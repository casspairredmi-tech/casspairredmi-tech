Diagrammes (configurables)

Le 2ᵉ graphique affiche un “statut” automatique selon la source (statut tâche, statut paiement, statut facture).

Aide (ultra simple)

  • Projet (en haut) filtre tout le site.
  • Mode tableur : clique une cellule → flèches pour naviguer, Entrée / F2 pour éditer, taper pour éditer directement.
  • Paiements en tranches : onglet “Paiements” ou “Tranches avancées…” → générer 30/40/30 avec choix des dates.
  • Drag & drop calendrier : sur Accueil (Mois/Semaine), glisse un paiement sur un jour pour changer son échéance.
  • Factures : table séparée, avec lien pièce jointe (URL).
  • Sauvegarde : menu “⋯” → Export/Import JSON.
