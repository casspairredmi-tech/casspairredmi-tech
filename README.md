# Demo PWA (GitHub Pages) — Cours & Quiz

## 1) Upload sur GitHub
- Repository → onglet **Code**
- Choisis ta branche (ex: `main` ou `Wap had`)
- **Add file → Upload files**
- Upload **TOUS** les fichiers du ZIP à la racine (pas dans un dossier)

## 2) Activer Pages
Settings → Pages
- Source: Deploy from a branch
- Branch: (ta branche) ; Folder: /(root)
- Save

## 3) Installer sur Android
Ouvre l’URL Pages dans Chrome → menu ⋮ → **Installer l’application**.

## Modifier tes cours
Édite `content.json`.
